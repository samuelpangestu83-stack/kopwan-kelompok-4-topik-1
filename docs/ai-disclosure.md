
# AI Disclosure

## 1. Penggunaan AI

Dalam pengerjaan proyek ini, ChatGPT digunakan sebagai alat bantu pengembangan sistem, penyelesaian kendala teknis, dan penyusunan dokumentasi.

| Bagian | Penggunaan AI | Verifikasi |
|---|---|---|
| Cloudflare Workers | Bantuan penulisan kode dan debugging pipeline | Pengujian endpoint dan eksekusi pipeline |
| Dashboard | Bantuan pengembangan tampilan dan integrasi data historis | Pemeriksaan tampilan dan kesesuaian data |
| Error Handling | Bantuan penyusunan skenario simulasi kegagalan | Pemeriksaan log dan status eksekusi pada D1 |
| Dokumentasi | Bantuan penyusunan arsitektur, runbook, laporan biaya, dan keamanan | Penyesuaian dengan implementasi dan bukti aktual |

## 2. Verifikasi Hasil

Hasil yang diberikan oleh AI diperiksa dan disesuaikan dengan kebutuhan proyek. Verifikasi dilakukan melalui pengujian sistem, pemeriksaan Cloudflare Dashboard, query database, serta pengecekan hasil pengolahan data.

Data penggunaan resource dan biaya aktual diperoleh langsung dari Cloudflare, bukan dihasilkan oleh AI.

## 3. Pernyataan Tanggung Jawab

AI digunakan sebagai alat bantu, bukan sebagai pengganti pemahaman dan tanggung jawab anggota kelompok. Seluruh hasil implementasi dan dokumentasi menjadi tanggung jawab kelompok.
